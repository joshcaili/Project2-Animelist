# Project2 - Animelist

A manga list app built with React and Vite. Users can add manga titles and authors, search through their list, and delete entries.

## How To Run locally

Clone the repo:
```
git clone https://github.com/joshcaili/Project2-Animelist
cd Project2-Animelist
```

Install npm if not installed already:
```
npm install
```

Start the dev server:
```
npm run dev
```

Open the URL Vite outputs in your terminal (default http://localhost:5173) in your browser.

To close the server,
Find the terminal where `npm run dev` is running, press:
```
Ctrl + C
```
